100 days, one structured roadmap, no skipping fundamentals. This repo is where I log daily progress — code, notes, and mini-projects — while working through data modeling, ETL/ELT, orchestration, big data, cloud, and production practices.

No tutorials-only approach here. Every phase ends in something built, not just something watched.
